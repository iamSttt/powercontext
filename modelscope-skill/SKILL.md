# 中文周报生成器

把零散的工作记录整理成结构清晰的中文周报。

## 使用场景

- 用户手头有零散的工作笔记、Git 提交记录、会议纪要或待办清单，需要汇总成周报
- 需要按「本周成果 / 问题与风险 / 下周计划」的结构组织内容
- 适合学生（实验、课程）、开发者（代码、上线）、职场人士（项目、协作）

## 输入

用户提供任意形式的原始素材，例如：

- 逐条列出本周做过的事（也可以混入时间、地点等杂项）
- 粘贴 Git 提交信息、聊天记录摘录或会议纪要
- 只给一句话概述（"这周主要在写数据库作业"）

## 处理步骤

1. **去重与归类**：识别并合并重复条目，把内容归入「成果」「问题」「计划」三类
2. **提炼成果**：每条成果用「动词 + 对象 + 结果」的格式改写，突出可验证的产出（如"完成 XX 模块的单元测试，覆盖率 85%"）
3. **归纳问题**：识别未完成事项、阻塞点和风险，说明原因与当前状态
4. **生成计划**：把未完成事项和下一步动作转为下周计划条目，每项可附优先级（高/中/低）

## 输出格式

```markdown
## 本周成果
1. …
2. …

## 问题与风险
1. …

## 下周计划
1. [高] …
2. [中] …
```

规则：

- 每类至少 1 条；素材不足以支撑某类时，如实写"无"
- 条目使用简洁的中文短句，单条不超过 60 字
- 不编造素材中不存在的工作内容
- 若用户指定了格式偏好（如按项目分组、要总结句），优先遵循用户要求

## 注意事项

- 素材可能是口语化、时间倒序或夹杂无关内容的，先清洗再归纳
- 用户说"不用写计划"时省略第三部分
