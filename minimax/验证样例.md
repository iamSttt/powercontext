# 验证样例：SDD 上下文模块

## 初始状态

- seekdb 运行于 `127.0.0.1:2881`（root 空密码）
- PowerContext Server 运行于 `127.0.0.1:8000`
- 业务工程中 `list_loans` **尚未支持** `status` 参数（`business/library/loans.py` 为修改前版本）
- `business/tests/test_loans_filter.py` 为本次目标测试（预期修改前失败）

## 步骤 1：索引工程资料

```bash
.venv/bin/python -m context_module.cli index --root .
```

**实际输出**

```json
{
  "indexed": 5,
  "paths": [
    "specs/loan-status-filter.md",
    "specs/regression-contract.md",
    "business/library/loans.py",
    "business/tests/test_loans_basic.py",
    "business/tests/test_loans_filter.py"
  ]
}
```

**seekdb 验证**（见 `records/seekdb-evidence.txt`）：表 `minimax_sdd.sdd_documents` 有 5 行，
含 `FULLTEXT KEY idx_fts_content (content) WITH PARSER ik`。

## 步骤 2：按任务检索上下文

```bash
.venv/bin/python -m context_module.cli context \
  --task "为借阅查询增加按状态筛选 status borrowed returned" --top 5
```

**实际输出（节选）**

```
命中的来源：
  - [spec] specs/loan-status-filter.md — 规格：借阅查询支持按状态筛选
  - [spec] specs/regression-contract.md — 回归契约：现有借阅行为必须保持
  - [code] business/library/loans.py — loans.py
  - [test] business/tests/test_loans_filter.py — test_loans_filter.py
  - [test] business/tests/test_loans_basic.py — 已归还且按时归还
```

输出包含本次必需的规格（SPEC-LOAN-002、SPEC-REG-001）、目标代码文件与两组测试，来源真实存在。

## 步骤 3：保存任务状态

```bash
.venv/bin/python -m context_module.cli state save --task-id T-001 --step context_built \
  --notes "命中5个来源：2规格+1代码+2测试"
```

**实际输出**：`{"saved": true, "task_id": "T-001", "response": {"memory": {"family": "memory", ...}}}`

## 步骤 4：重启模块后复用状态

新起一个进程（模拟模块重启）：

```bash
.venv/bin/python -m context_module.cli state load --task-id T-001
```

**实际输出**：`status: ready`，`content` 中包含此前保存的 `context_built` 进展（PowerContext PreparedContext）。

## 步骤 5：MiniMax 完成代码修改

```bash
MINIMAX_API_KEY=... .venv/bin/python scripts/run_minimax_change.py
```

**实际输出**：`{"ok": true, "elapsed": 8.2, "usage": {"total_tokens": 3472, "prompt_tokens": 2546, "completion_tokens": 926}}`

记录见 `records/minimax-development-record.md`（提示词、上下文来源、响应、推理片段、token 用量）。

## 重置方法

```bash
# 恢复修改前的业务代码
cp records/loans-before.py business/library/loans.py
# 清空 seekdb 索引（重新执行 index 会重建）
docker exec seekdb mysql -h127.0.0.1 -P2881 -uroot -e "DROP DATABASE IF EXISTS minimax_sdd;"
# 清空 PowerContext 状态：删除 ~/.local/share/powercontext 下的 SQLite 文件后重启 server
```
